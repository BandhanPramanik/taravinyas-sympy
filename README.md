# taravinyas-sympy
All the Sympy codes for Taravinyas for various scripts

# How to run

1. Go to the root directory of this repo.

2. Use the following syntax (use python or python3):

MacOS or Linux:

```python
python3 -m <parent_directory>.<filename_without_py>
```

Windows:

```python
python -m <parent_directory>.<filename_without_py>
```

`<parent_directory>`: enter the directory name

`<filename_without_py>`: suppose your code is named `abc.py`. You will just write `abc`.
